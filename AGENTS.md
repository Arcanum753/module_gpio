# module_gpio — управление GPIO через web

> **Опциональный модуль.** Подключается через `src_filter` + `build_flags`.
> **Работоспособен только в составе сборки, содержащей ядро** (см. `../../TRS.md` §2.1).

Минимальный веб-модуль управления GPIO (демонстрационный). Разбирает аргументы формы
`uartstr`/`led1..led4`.

- **Репозиторий:** https://github.com/Arcanum753/module_gpio
- **Папка:** `src/module_gpio/`
- **Флаг активации:** `-D MODULE_GPIO` (в env встречается `-D MODULE_GPIO=1`)
- **Registry:** `object=module_gpio`, `define=MODULE_GPIO`, `web=1`, `loop=0` (без `namespace`/`res`/`prio`)
- **Только для платформы:** обе (ESP8266/ESP32)
- **Зависит от модулей:** —
- **Зависит от ядра:** `core_web`, `core_sys`

## Назначение

Обеспечивает:
- Управление пинами GPIO через веб-интерфейс;
- Чтение состояния пинов;
- Установка режима (INPUT/OUTPUT).

> [!WARNING]
> **Данный модуль находится в стадии активной разработки. API и функционал могут изменяться. Подробное руководство пользователя будет добавлено по мере стабилизации.**

## Функциональные требования

- FR-GPIO-1: `POST /gpio` — приём параметров формы; запись выходов выполняет обработчик.
- FR-GPIO-2: Конфиг отсутствует.

## Веб-интерфейс

Страница `gpio.html` (пункт меню — `web/_menu.html`); маршрут `POST /gpio`.

## Слоистая структура

Из `../../LAYERS.md`: `module_gpio` — логики почти нет; выносить нечего.

## Критерии приёмки

- См. AC-15 (`module_template`/`module_gpio` собираются и открывают свои страницы); каноническое описание — в `../module_template/AGENTS.md`.

## Ограничения и известные проблемы

- `html_ver_get` существует, но маршрут `/gpio/ver` не зарегистрирован; функциональность неполная — модуль-заглушка.
- См. OPEN-7 (каноническое описание — в `../module_rgb/AGENTS.md`): у `module_gpio` нет resource-bus, модуль недоступен из макросов.
